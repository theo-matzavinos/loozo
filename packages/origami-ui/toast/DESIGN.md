# Toast design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 28.

```text
OrigamiToaster<T> (the consumer's @Service subclass)
 │  ToastStore: entries in add order, each { record, duration, status: waiting | shown | closing }
 │  add(id?) ──untracked──▶ by the id's status (nothing kept on the server):
 │     none: append waiting, offer │ waiting: swap in its slot │ shown: region restart, swap in its slot
 │     closing: drop it, append waiting, offer │ a throwing offer undoes only this add's own entry
 │  close(id) ──▶ waiting: dropped; shown: the region's close; closing or unknown: nothing
 └─ one region ──register(ngOnInit)──▶ a second region on the same toaster throws;
      its DestroyRef unregisters: shown ──▶ waiting (full duration), closing ──▶ dropped
OrigamiToastRegion   ToastRegionContext: blocked (dialog:modal), paused (hover | focus within | document.hidden),
 │                   a timer per shown record, limit, focus-return target, frame check
 │   release: waiting ──▶ shown, oldest first, at offer, at register, on any dialog's captured toggle/close
 │            and on the frame check while held; unless blocked (then held: still waiting, no time, and
 │            a frame check scheduled); each record only while the region lives and it still waits;
 │            then the limit closes the oldest open
 │   state.toasts = shown + closing, newest first
 └─ Toast ──register(ngOnInit), its record's id read live──▶ the region; Presence present = record shown
      host inert = record closing (its exit)
      Presence settled closed, or the Toast destroyed ──▶ region drops its closing record
      └─ Close ── click ──▶ the region's close of its Toast's record
```

The release is the region's one gate from waiting to shown, so the modal hold is a check in it and a re-run from the dialog events that lift it and, while it holds records, from every animation frame, with no change of owner. Detection reads the DOM, so `/toast` doesn't depend on `/dialog`.

## Ownership

| Fact                     | Owner                                                                                                                                                                                                                                     | Readers                                                                                                                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Records and their status | the toaster's `ToastStore`, a signal of immutable entries: written by `add` and `close` (any context, untracked) and by its region's release, close and drop                                                                              | the region's Context (release, close, limit, focus), Region State `toasts`, each Toast's `open`                                                                           |
| Toast ids                | the caller's `id`, scoped to its toaster; else a module-level counter in `toaster.ts`, so generated ids are unique across toasters, whose allocation skips an id this toaster holds                                                       | the consumer, `close(id)`, `add`'s replace                                                                                                                                |
| The toaster's region     | the store: set by the region's `ngOnInit` registration, cleared by its `DestroyRef`; a second registration throws                                                                                                                         | `add` (offer) and `close`                                                                                                                                                 |
| Bound toaster            | the effective `OrigamiToastRegionOptions.toaster`, read once at registration; the Context keeps that toaster's store in a signal                                                                                                          | Region State, the Context                                                                                                                                                 |
| Duration, limit          | the effective `OrigamiToastRegionOptions`; a toast's own `duration` in its entry                                                                                                                                                          | the release; a shown replace's `restart`, the `duration` only, when the replace has none of its own                                                                       |
| Blocked                  | the region's Context: `document.querySelector("dialog:modal")`, read at each release that has waiting records; not stored                                                                                                                 | the release, which holds every waiting record while it matches                                                                                                            |
| Frame check              | the region's Context: one pending `requestAnimationFrame` handle, set by a release that holds records when none is pending, cleared when it runs or the region is destroyed                                                               | its callback, which re-runs the release                                                                                                                                   |
| Paused                   | the region's Context: hover from host `pointerenter`/`pointerleave`; focus within read live (`focusin`/`focusout` supply it); the document's `visibilitychange`                                                                           | the timers, in those events, at a release, at a shown replace's `restart`, after the render that follows a shown replace and after a Toast's or Close's view is destroyed |
| Timers, remaining time   | the region's Context, one per shown record from its release to its close, replaced by a shown replace's `restart` (also before its Toast registers); cleared when the region is destroyed                                                 | timer callbacks, which close                                                                                                                                              |
| Mounted Toasts           | the region's Context: a list of `{ id, element }`, appended by each Toast's `ngOnInit`, removed by its `DestroyRef`                                                                                                                       | the close (focus, and dropping a record no Toast renders)                                                                                                                 |
| Toast open               | derived: its record's status is `shown`, through the region's Context                                                                                                                                                                     | Toast State, its Presence `present`, its host `inert` (not open)                                                                                                          |
| Exit settled             | the Toast's composed Presence                                                                                                                                                                                                             | the Toast Context's effect, which tells the region to drop the closing record                                                                                             |
| Close target             | Close's nearest Toast (DI)                                                                                                                                                                                                                | its click handler                                                                                                                                                         |
| Focus-return target      | the region's Context: the `relatedTarget` of a host `focusin` from an element outside; a host `focusout` to an element outside clears it; either event without a `relatedTarget` (window reactivation, focus to or from nothing) keeps it | the close, when the closing Toast contains the focused element                                                                                                            |

## Refresh dependencies

- A released record renders on the next change detection, which the store's signal schedules under zoneless change detection. The Toast for it registers in that view's `ngOnInit`; until then the region treats the record as having no Toast, so a close in that window drops it and it never renders. Nothing tracks turns: registration is the only signal.
- A close changes the record's status before it moves focus, and the close writes nothing after the focus move; the limit counts the open records again before each further close: a focus listener that destroys the region finds the record closing and the store's teardown drops it. The next render turns the Toast's Presence `present` false and binds `data-leaving`. Presence settles in its after-render READ or when its animations finish; the Toast Context's effect then drops the record, and the render after that removes the consumer's view.
- A release of several records, such as held ones, checks before each record, before writing its status or its timer, that the region isn't destroyed, that no modal dialog blocks the page and that the record is still waiting: the previous record's limit close moves focus, whose listeners may destroy or replace the region, open a modal dialog or close a record. The records it didn't reach stay waiting, for the region registered next or the next release.
- A release from a dialog's `toggle` or `close` runs in a plain document listener, and the frame check in a `requestAnimationFrame` callback, outside Angular's template listeners: the store's signal write schedules the change detection that renders the released records, as for an `add` from any context.
- A shown replace re-renders the same view: the same key in the same slot means `@for` updates the view's record in place. A closing re-add keeps the view only if no render saw the id absent; Presence reverses only once its exit rendered. The pause check a shown replace registers runs after the render that may remove focused content.
- The region registers in its `ngOnInit` and sets its store signal, so the consumer's `@for` over `state.toasts()` renders the released records in the same change detection pass or the next.
