# Switch design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 21.

## Ownership

| Fact                                                        | Owner                                                                                                                                                                                          | Readers                                                                                                                                  |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Checked                                                     | the effective `OrigamiSwitchOptions.checked`: the directive's own model by default, which `[formField]` binds, or a replacement                                                                | the host bindings, State; written by the Switch's guarded activation and by its owner                                                    |
| Disabled, focusable when disabled                           | the effective Options; `[formField]` writes the own `disabled` input from the field's `disabled()` rules                                                                                       | the guard, State, the composed `ogButton`'s Options factory                                                                              |
| ID                                                          | the effective Options `id`                                                                                                                                                                     | the host `id`; the Field's Labels through the registration                                                                               |
| Value, touched, readonly, required, validation, errors      | Angular's `FieldState`, bound by the `[formField]` on the same element                                                                                                                         | the Switch's `ɵOrigamiFieldMembership` (`FORM_FIELD`, self): the guard and its ARIA                                                      |
| Field membership: ID, labelable, form state reader          | the nearest `ogField`'s control slot, set by the Switch's registration in `ngOnInit`                                                                                                           | the Field's Labels, State and data attributes; the Switch's own Field ARIA                                                               |
| Description and Error IDs, `errorsShown`                    | the nearest Field                                                                                                                                                                              | the Switch's membership, which registers the IDs with `ɵOrigamiDescribedBy` while it is the Field's control; the Switch's `aria-invalid` |
| `aria-describedby`                                          | `ɵOrigamiDescribedBy` (`/utils`), one per element, composed by the Switch and by a co-applied Tooltip Trigger: every registration's IDs in registration order, else the element's static value | the element                                                                                                                              |
| Touch notification                                          | the private Context's Observable, emitted on blur                                                                                                                                              | the `touch` output, which `[formField]` listens to                                                                                       |
| `type`, native `disabled`, `aria-disabled`, `data-disabled` | the composed `ogButton`                                                                                                                                                                        | the DOM                                                                                                                                  |

## Read timing

| Read                                                  | Reader                                                          | Phase        | Platform | If the owner isn't initialized                                                                                               |
| ----------------------------------------------------- | --------------------------------------------------------------- | ------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Own Options (`checked`, `disabled`, `id`, …)          | host bindings, State, `ogButton`'s Options                      | render       | both     | Safe: its own, read through `injectDeferred` after construction.                                                             |
| Own Options `id`                                      | the Field registration, through the Labels                      | render       | both     | Registered in `ngOnInit`, after Angular set the inputs, so a Label never sees the default in place of a bound ID.            |
| `FORM_FIELD.state()`                                  | the Field ARIA, through the membership                          | render       | both     | Angular sets `[formField]` on the same element before the Switch's first host-binding update; without `[formField]`, absent. |
| `FORM_FIELD.state().readonly()`                       | the activation guard                                            | event        | browser  | Safe: read at click time.                                                                                                    |
| The Field's slot (`control()`), Description/Error IDs | the Switch's Field ARIA; its `ɵOrigamiDescribedBy` registration | render       | both     | Before its own registration it isn't the member: it renders its static ARIA attributes.                                      |
| Static ARIA attributes                                | the membership, `ɵOrigamiDescribedBy`                           | construction | both     | Safe: the element's own, including a composing directive's `host` ones.                                                      |

## Refresh dependencies

- The Field's Labels, State and data attributes depend on the render that follows the Switch's registration, as for any Field control (see the [Field design map](../field/DESIGN.md)); on the server too, so server HTML is complete.
- The Field ARIA depends on the render that follows a Signal Forms change (blur, `submit()`, a rule): it reads `FieldState` signals.
