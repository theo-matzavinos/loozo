# Meter design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 37.

## Ownership

| Fact                                 | Owner                                                                                                   | Readers                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Options (value, min, max, valueText) | the root directive through `OrigamiMeterOptions` (`provideExisting`), or a composer's whole replacement | the Context (deferred with `injectDeferred`)        |
| Effective min                        | the Context: Options `min` when finite, else 0                                                          | `aria-valuemin`; max, value, percent                |
| Effective max                        | the Context: Options `max` when finite, else 100, raised to the effective min when below it             | `aria-valuemax`; value, percent                     |
| Rendered value                       | the Context: Options `value` clamped to [min, max]; min when not finite                                 | `aria-valuenow`; percent; State `value`             |
| Percent                              | the Context: (value − min) ÷ (max − min) × 100, 0 when max equals min                                   | `--og-meter-percent`; default text; State `percent` |
| Value text                           | the Context: Options `valueText`, else the Intl percent of percent ÷ 100                                | `aria-valuetext`; State `valueText`                 |
| Locale                               | `LOCALE_ID` from the root element's injector, injected once in the Context's constructor                | the default formatter, created on first use         |
| Accessible name                      | the consumer: static, bound or composer-host `aria-label` / `aria-labelledby`                           | the browser; Origami never reads or writes it       |
| Drawing and its `aria-hidden`        | the consumer                                                                                            | the browser                                         |

## Read timing

| Read                   | Reader                                                                                                                                     | Phase                                              | Platform | If the owner isn't initialized                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root Options           | the Context's `computed`s, through State or the root's host bindings                                                                       | construction at the earliest, render at the latest | both     | Deferred with `injectDeferred`: resolved on the first evaluation of a Context `computed`, whichever comes first, a consumer's State read or the root's host bindings in the first update pass. The root's own Options: a bound `value` is unset before the root's update-pass bindings run, and reading it then throws NG0950 (see State). A replacement's signals hold whatever they hold at that first read and must be complete.                                    |
| `LOCALE_ID`            | the Context's constructor                                                                                                                  | construction                                       | both     | Always provided (Angular defaults it to `en-US`); the nearest injector of the root's element, so a subtree may override it.                                                                                                                                                                                                                                                                                                                                            |
| State, evaluated early | a descendant's or composer's constructor or field initializer; a template binding placed before the root                                   | construction, or render before the root's bindings | both     | Injecting State is safe. Evaluating a State signal reads the required `value`: with a bound `value` it's unset and throws NG0950: at construction the route's server render fails, and in a template binding before the root the update pass stops there, so the root's host bindings never run and the meter has no value attributes, on the server and in the browser; with a static `value` attribute it's already set. Unsupported; README, TSDoc and SPEC say so. |
| State, evaluated late  | template and host bindings inside or after the root, a composer's template, a lazy `computed`, `ngOnInit` and later hooks, effects, events | render or later                                    | both     | The root's inputs are set: the update pass sets them before any of these run.                                                                                                                                                                                                                                                                                                                                                                                          |

## Refresh dependencies

- None for the first render: every bound fact is computed synchronously from Options and `LOCALE_ID` no later than the root's host-binding pass, on the server too. Server HTML needs no second pass.
- After that, each write to a value, min, max or valueText signal (an input, a replacement signal, a signal written from a timer) marks the view that declares the root's element for refresh. Inputs bound in one template change together in one pass, before the host bindings read them. Within that pass Angular writes each attribute separately; the in-bounds invariant holds per settled pass.
- Incremental hydration: a root in a still-dehydrated `@defer` block keeps the server's attributes until the block hydrates, and renders the current values in the hydrating change detection.
