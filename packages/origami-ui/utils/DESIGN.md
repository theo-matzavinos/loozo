# Utilities design map

Ownership and read timing for `injectUniqueId`, `injectUniqueValue`, `injectDeferred` and the package-private `ɵOrigamiDescribedBy`. Usage is in the [README](README.md); the contract is SPEC section 5.

## Ownership

| Fact                                        | Owner                                                                                                                                                                                                              | Readers                                                  |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| The next number per key                     | `IdCounter` (`id-counter.ts`), one application `@Service`                                                                                                                                                          | `injectUniqueId`, `injectUniqueValue`                    |
| Server or browser namespace (`s` prefix)    | `IdCounter.server`, from `PLATFORM_ID`                                                                                                                                                                             | `injectUniqueId`                                         |
| A hydrated element's ID                     | the host element's rendered `id` attribute, written by the server render                                                                                                                                           | `injectUniqueId` in the browser                          |
| Key validity                                | `assertKey` (`id-counter.ts`)                                                                                                                                                                                      | both allocators, before allocating                       |
| The injector a deferred token resolves from | the function `injectDeferred` returns, which captures it                                                                                                                                                           | whoever calls that function                              |
| An element's `aria-describedby`             | `ɵOrigamiDescribedBy`, one per element however many matched directives compose it through `hostDirectives`; its registrations, each added by a describer's `ngOnInit` and removed when that describer is destroyed | its own `[attr.aria-describedby]`                        |
| The element's static `aria-describedby`     | the element, written by Angular from the template and every matched directive's `host` before it creates directives; a hydrated element also carries the server binding's output there                             | `ɵOrigamiDescribedBy`, while no registration names an ID |
| Whether that value is the server's output   | `ɵOrigamiDescribedBy`'s `linkedSignal`: yes once the registrations' IDs equal it, kept from then on                                                                                                                | its own `[attr.aria-describedby]`                        |

## Read timing

| Read                          | Reader                                            | Phase                                | Platform | If the owner isn't initialized                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------- | ------------------------------------------------- | ------------------------------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `host.getAttribute("id")`     | `injectUniqueId`, as an `id` input's default      | construction                         | browser  | A client-created host has no rendered `id` yet: the counter allocates `og-<key>-<n>`. A hydrating host returns the server's ID.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `IdCounter.next(key)`         | both allocators                                   | construction (any injection context) | both     | n/a: the counter is the owner.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| The deferred token            | the function `injectDeferred` returns             | when called                          | both     | Callers call it at render time only for their own Options or an ancestor's (SPEC section 3, rule 1).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| The static `aria-describedby` | `ɵOrigamiDescribedBy`                             | construction                         | both     | Safe: the element's own. Under hydration it may be the server's IDs instead of a consumer value; the next row decides.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| The snapshot rule             | `ɵOrigamiDescribedBy`'s `[attr.aria-describedby]` | render, every evaluation             | both     | While no registration names an ID, the construction-time value is rendered, which matches the server HTML. Every evaluation compares the IDs: once they equal exactly that value, it was the server's output and there is no static fallback from then on; until then it stays the fallback. A describer that registers after the element's host bindings, such as Content in a child component's view, is waited for whether the IDs first name nothing or part of the server's list; Angular re-evaluates the binding in the same change detection once it registers, so the full list is compared. |
| Each registration's IDs       | `ɵOrigamiDescribedBy`'s `[attr.aria-describedby]` | render                               | both     | A describer registers in its `ngOnInit`, so its IDs follow those of describers that initialized before it, in Angular's directive order on the element; before any registration names an ID, the static value.                                                                                                                                                                                                                                                                                                                                                                                        |

The allocators make no render-time reads, and nothing self-corrects.
