# ToggleGroup design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 14.

## Ownership

| Fact                                                   | Owner                                                                                                                                               | Readers                                                                                                                                                                                   |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Value, disabled, orientation, `deselectable`           | the mode's Options (`OrigamiToggleGroupSingleOptions` or `…MultipleOptions`), on `ogToggleGroupSingle`/`Multiple` or the Toolbar's Toggle Groups    | the root Options the mode supplies through `ɵprovideRoot`                                                                                                                                 |
| Disabled, orientation, pressed values, the write rule  | `ToggleGroupRootOptions`, built from the mode Options; for a Toolbar Toggle Group the orientation is the Toolbar's                                  | `ToggleGroupContext` in `ɵOrigamiToggleGroupRoot`                                                                                                                                         |
| An item's value, disabled, focusable when disabled     | its `OrigamiToggleGroupItemOptions`                                                                                                                 | its `ToggleGroupItemContext`; the roving focus through its registered item; the composed Toggle's Options, and through Toggle the composed `ogButton`, which owns the disabled attributes |
| An item's checked (pressed) state                      | derived: `root.selected(own value)`, a `linkedSignal` whose writes become root requests                                                             | the composed Toggle, as its Options; applications through the item's `state` (the Toggle's State)                                                                                         |
| An item's ID                                           | its `OrigamiToggleGroupItemOptions`                                                                                                                 | its `ToggleGroupItemContext`; the composed Toggle, as its Options `id`, which binds it as the host `id`                                                                                   |
| That an item isn't a form control                      | the item, which provides `ɵOrigamiToggleNotFormControl` on its element                                                                              | the composed Toggle, which then joins no Field and registers no description                                                                                                               |
| Roving membership and tab stop                         | the nearest `ɵOrigamiRovingFocusContext`: the standalone root's own, or the Toolbar's for a Toolbar Toggle Group; each item registers in `ngOnInit` | the item's `[tabindex]`                                                                                                                                                                   |
| Roving policy (standalone)                             | `ownRovingFocus`: the root's orientation, `preferred` = the pressed values                                                                          | the roving Context                                                                                                                                                                        |
| Value, touched, readonly, required, validation, errors | Angular's `FieldState`, bound by the `[formField]` on the root's element                                                                            | `ToggleGroupContext` (`FORM_FIELD`, self): the readonly guard in `request`; the Single or Multiple root's `ɵOrigamiFieldMembership`: `aria-labelledby` and the Field                      |
| Field membership: form state reader (not labelable)    | the nearest `ogField`'s control slot, set by the Single or Multiple root's registration in `ngOnInit`; a Toolbar Toggle Group never registers       | the Field's State and data attributes                                                                                                                                                     |
| Label IDs                                              | the nearest Field's Label slot, set by each `ogFieldLabel` in `ngOnInit`                                                                            | the root's `aria-labelledby`, through its membership, while it is the Field's control                                                                                                     |
| Description and Error IDs                              | the nearest Field                                                                                                                                   | the root's membership, which registers them with `ɵOrigamiDescribedBy` while it is the Field's control                                                                                    |
| `aria-describedby`                                     | `ɵOrigamiDescribedBy` (`/utils`), composed by the Single and Multiple roots                                                                         | the element                                                                                                                                                                               |
| Static `aria-labelledby`                               | the element, read at construction by the membership                                                                                                 | the root's binding outside a Field and as a second control the Field ignores                                                                                                              |
| Touch notification                                     | `ToggleGroupContext`'s Observable, emitted when the Single or Multiple root's `focusout` moves focus outside its element                            | the root's `touch` output, which `[formField]` listens to                                                                                                                                 |
| The element `focus()` focuses                          | the Single or Multiple root's own roving Context's tab stop                                                                                         | `focus()`, which `focusBoundControl()` calls                                                                                                                                              |

## Read timing

| Read                                    | Reader                                           | Phase        | Platform | If the owner isn't initialized                                                                                                                                                                  |
| --------------------------------------- | ------------------------------------------------ | ------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Own value, root pressed values          | the item's `checked`                             | render       | both     | Safe: own inputs and an ancestor.                                                                                                                                                               |
| Item Options `id`                       | the Toggle's host `[id]`                         | render       | both     | Safe: the item's own Options, read after Angular sets its inputs.                                                                                                                               |
| Root disabled, orientation              | root host bindings, items                        | render       | both     | Safe: the root's own or an ancestor's Options. A Toolbar Toggle Group's orientation is the Toolbar's, an ancestor.                                                                              |
| Roving tab stop                         | item `[attr.tabindex]`                           | render       | both     | See the roving focus in [collection/DESIGN.md](../collection/DESIGN.md).                                                                                                                        |
| Live disabled state, focusable          | `clicked()`                                      | event        | browser  | Safe.                                                                                                                                                                                           |
| `FORM_FIELD.state().readonly()`         | `ToggleGroupContext.request`                     | event        | browser  | Safe: read at request time; without `[formField]`, absent.                                                                                                                                      |
| `FORM_FIELD.state()`                    | the Field, through the membership                | render       | both     | Angular sets `[formField]` on the same element before the root's first host-binding update; without it, absent.                                                                                 |
| The Field's slot, Label IDs             | `[attr.aria-labelledby]`, through the membership | render       | both     | Before its own registration the root isn't the member: it renders its static value. A Label in a later sibling view or a child component is absent until it registers; server HTML is complete. |
| The Field's slot, Description/Error IDs | the root's `ɵOrigamiDescribedBy` registration    | render       | both     | As for any Field control (see the [Field design map](../field/DESIGN.md)).                                                                                                                      |
| Static `aria-labelledby`                | the membership                                   | construction | both     | Safe: the element's own. Under hydration it may be the server's output, which the member never reads; outside a Field and as an ignored control the server rendered the same static value.      |
| `focusout` `relatedTarget`              | the touch notification                           | event        | browser  | Safe: the event's own; null (focus left to nothing) touches.                                                                                                                                    |
| Own roving tab stop                     | `focus()`                                        | event        | browser  | Safe: read when called; null focuses nothing.                                                                                                                                                   |
