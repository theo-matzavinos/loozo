# ToggleGroup design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 14.

## Ownership

| Fact                                                  | Owner                                                                                                                                               | Readers                                                                                                                                                                                   |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Value, disabled, orientation, `deselectable`          | the mode's Options (`OrigamiToggleGroupSingleOptions` or `…MultipleOptions`), on `ogToggleGroupSingle`/`Multiple` or the Toolbar's Toggle Groups    | the root Options the mode supplies through `ɵprovideRoot`                                                                                                                                 |
| Disabled, orientation, pressed values, the write rule | `ToggleGroupRootOptions`, built from the mode Options; for a Toolbar Toggle Group the orientation is the Toolbar's                                  | `ToggleGroupContext` in `ɵOrigamiToggleGroupRoot`                                                                                                                                         |
| An item's value, disabled, focusable when disabled    | its `OrigamiToggleGroupItemOptions`                                                                                                                 | its `ToggleGroupItemContext`; the roving focus through its registered item; the composed Toggle's Options, and through Toggle the composed `ogButton`, which owns the disabled attributes |
| An item's checked (pressed) state                     | derived: `root.selected(own value)`, a `linkedSignal` whose writes become root requests                                                             | the composed Toggle, as its Options; applications through the item's `state` (the Toggle's State)                                                                                         |
| An item's ID                                          | its `OrigamiToggleGroupItemOptions`                                                                                                                 | its `ToggleGroupItemContext`; the composed Toggle, as its Options `id`, which binds it as the host `id`                                                                                   |
| That an item isn't a form control                     | the item, which provides `ɵOrigamiToggleNotFormControl` on its element                                                                              | the composed Toggle, which then joins no Field and registers no description                                                                                                               |
| Roving membership and tab stop                        | the nearest `ɵOrigamiRovingFocusContext`: the standalone root's own, or the Toolbar's for a Toolbar Toggle Group; each item registers in `ngOnInit` | the item's `[tabindex]`                                                                                                                                                                   |
| Roving policy (standalone)                            | `ownRovingFocus`: the root's orientation, `preferred` = the pressed values                                                                          | the roving Context                                                                                                                                                                        |

## Read timing

| Read                           | Reader                    | Phase  | Platform | If the owner isn't initialized                                                                                     |
| ------------------------------ | ------------------------- | ------ | -------- | ------------------------------------------------------------------------------------------------------------------ |
| Own value, root pressed values | the item's `checked`      | render | both     | Safe: own inputs and an ancestor.                                                                                  |
| Item Options `id`              | the Toggle's host `[id]`  | render | both     | Safe: the item's own Options, read after Angular sets its inputs.                                                  |
| Root disabled, orientation     | root host bindings, items | render | both     | Safe: the root's own or an ancestor's Options. A Toolbar Toggle Group's orientation is the Toolbar's, an ancestor. |
| Roving tab stop                | item `[attr.tabindex]`    | render | both     | See the roving focus in [collection/DESIGN.md](../collection/DESIGN.md).                                           |
| Live disabled state, focusable | `clicked()`               | event  | browser  | Safe.                                                                                                              |
