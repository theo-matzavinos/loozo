# Accordion design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 9.

## Ownership

| Fact                                                          | Owner                                                                                                                                | Readers                                                                                                                                                             |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Selection, collapsible policy                                 | the mode's Options (`OrigamiAccordionSingleOptions` or `…MultipleOptions`), through the mode's `Selection`                           | `AccordionContext`                                                                                                                                                  |
| Disabled                                                      | `OrigamiAccordionOptions`                                                                                                            | `AccordionContext`, every item                                                                                                                                      |
| An item's value                                               | the item's Collection Item Options (by default its `OrigamiAccordionItemOptions` value, by default the Accordion Item's own `value`) | its `AccordionItemContext`; `itemValues` through its Collection record                                                                                              |
| An item's disabled state, hiding                              | the item's `OrigamiAccordionItemOptions` (by default the Accordion Item's own inputs), adapted to the composed Collapsible's Options | the Collapsible and its parts (`hiding` through the adapted Collapsible Options); applications read `disabled` through the item's `state` (the Collapsible's State) |
| An item's expanded state                                      | derived: `root.selected(own value)`, a `linkedSignal` whose writes become root requests                                              | the composed Collapsible, as its `expanded`; applications through the item's `state`                                                                                |
| An item's lock (Single, selected, not collapsible)            | derived: `root.locked(own value)`                                                                                                    | the composed Collapsible Trigger, as its Options' `disabled`, focusable unless the item or root is disabled and the Trigger isn't focusable when disabled           |
| The Trigger's focusability while the item or root disables it | `OrigamiAccordionTriggerOptions` (by default the Accordion Trigger's own `focusableWhenDisabled` input)                              | the composed Collapsible Trigger's Options' `focusableWhenDisabled`, and through them the composed Button's disabled attributes                                     |
| Item membership and order                                     | the composed Collection; each item registers in `ngOnInit`                                                                           | `OrigamiAccordionState.itemValues`                                                                                                                                  |
| Trigger and Panel slots                                       | the item's composed Collapsible; the composed Collapsible Trigger and Panel register in `ngOnInit`                                   | as in [collapsible/DESIGN.md](../collapsible/DESIGN.md)                                                                                                             |
| The Panel's presence                                          | the composed Collapsible Panel's Presence                                                                                            | as in [collapsible/DESIGN.md](../collapsible/DESIGN.md); applications through `ogAccordionPanel`'s `state`                                                          |

## Read timing

| Read                      | Reader                                                     | Phase                                            | Platform | If the owner isn't initialized                                                                                 |
| ------------------------- | ---------------------------------------------------------- | ------------------------------------------------ | -------- | -------------------------------------------------------------------------------------------------------------- |
| Own value, root selection | the item's `expanded`, `locked`                            | render                                           | both     | Safe: own inputs and an ancestor.                                                                              |
| Own item Options          | the lower Collection Item and Collapsible Options adapters | after construction, at their first read (render) | both     | Safe: own element; resolved only after construction, so replacement Options may use the item's inputs.         |
| Item lock, item disabled  | the Trigger's lower Collapsible Trigger Options            | render                                           | both     | Safe: an ancestor's.                                                                                           |
| Own Trigger Options       | the Trigger's lower Collapsible Trigger Options            | render                                           | both     | Safe: its own, resolved after construction.                                                                    |
| Registered items' values  | `itemValues`, read by applications                         | render, mostly                                   | both     | Unregistered items aren't listed; later `@for` items join when they register. A keyed move notifies no reader. |
| Trigger and Panel IDs     | the Collapsible parts                                      | render                                           | both     | As in [collapsible/DESIGN.md](../collapsible/DESIGN.md).                                                       |
