## Read timing

| Read                                    | Reader                                                                               | Phase        | Platform | If the owner isn't ready                                                                                                                                                                                                                   |
| --------------------------------------- | ------------------------------------------------------------------------------------ | ------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Analysis, query                         | Context computeds                                                                    | render       | both     | `injectDeferred`; a null analysis is nothing current                                                                                                                                                                                       |
| Caret, composition                      | State, the gate                                                                      | render       | both     | null until the Input attaches and is focused; always null on the server                                                                                                                                                                    |
| Content, rows and Message registrations | the gate, ARIA                                                                       | render       | both     | absent until registered: not presentable, `aria-controls` absent                                                                                                                                                                           |
| The gate                                | the rendered gate                                                                    | after render | browser  | false until the first render, so the server never presents                                                                                                                                                                                 |
| Element text, selection, scroll offset  | the handlers, keys, the pick                                                         | event        | browser  | read live                                                                                                                                                                                                                                  |
| Query against the element's text        | the reconcile (`afterRenderEffect` over the query and the composition)               | after render | browser  | skipped before the first render (the attach runs instead), during a composition and a pick                                                                                                                                                 |
| Caret at attach                         | the attach read                                                                      | first render | browser  | read only while focused                                                                                                                                                                                                                    |
| Tokens at the old and new caret         | the movement rule                                                                    | event        | browser  | stale tokens are `[]`: nothing opens                                                                                                                                                                                                       |
| Current suggestions, the caret token    | the known-empty effect                                                               | effect       | both     | loading never closes; an invalid caret token never closes                                                                                                                                                                                  |
| Participation                           | the Escape, Tab, Alt+ArrowUp and outside-press classifications                       | event        | browser  | the last synchronized signal, then `isParticipating()` for the keys while Shown; read before any caret read the key brings, a waiting focus read included                                                                                  |
| Caret at a focus                        | the focus read; a read at `[0, 0]` waits for the next `selectionchange`, key or task | event, task  | browser  | `[0, 0]` (WebKit's transient during `focus`) publishes nothing at the event; the waiting read compares with the selection kept at rest, a movement starts from that kept collapsed selection, and a focus generation drops a replaced wait |
| Effective highlight, request            | the highlight effect (marks a snapshot presented, lapses or retires it)              | effect       | both     | a snapshot prepared while Opening stays unpresented until Shown                                                                                                                                                                            |

## Refresh dependencies

- The reconcile runs at the next render after an outside write or a composition's end.
- Your analysis catches up with the query only after its binding refreshes, so opening is event-driven and closing as known empty is effect-driven.
- Within one refresh the root's view sees the new analysis before the rows' embedded views show the new suggestions, so the live gate can read false for one pass; the Popover reads the gate as the last completed render left it, so that pass neither hides nor shows the list.
- `caretChange` from the reconcile or the attach read makes Angular render again.
