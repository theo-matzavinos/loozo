# Dialog design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 22. The dismissal layer and the presentation contract Content implements are mapped in [utils/DESIGN.md](../utils/DESIGN.md).

```text
OrigamiAlertDialog      own Options (OrigamiAlertDialogOptions) ──▶ the composed root's OrigamiDialogOptions;
 │                        provides ɵOrigamiDialogRole = "alertdialog" on the root's element
OrigamiDialog (root)    DialogContext: requested open, dismissible, role, registrations
 ├─ Trigger      ──register(ngOnInit)──▶ trigger slot   (aria-controls, focus fallback)
 ├─ Content      ──register(ngOnInit)──▶ content slot
 │    DialogSession (provided on Content): native modal session, layer, modal scope
 │      ──register(construction)──▶ ModalSessions; its layer ──▶ ɵOrigamiLayers' modal scopes
 │    DialogDescriptions (provided on Content): description IDs (Content's ɵOrigamiDescribedBy)
 │    ModalSessions (application): mounted Contents, scroll lock, topmost session
 │    └─ Description* ──register(ngOnInit)──▶ the nearest Content's description IDs
 ├─ Title*       ──register(ngOnInit)──▶ title IDs        (Content's aria-labelledby)
 └─ Close        ── click ──▶ open = false
```

## Ownership

| Fact                                             | Owner                                                                                                                                                                                                                                                            | Readers                                                                                                                                       |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Requested open                                   | the effective `OrigamiDialogOptions.open`: the root's model by default, or a replacement; under `ogAlertDialog`, the effective `OrigamiAlertDialogOptions.open`, its own model by default                                                                        | `DialogContext.intent` (a new object per decision), root State, Trigger `aria-expanded`, Content's Presence, `DialogSession`                  |
| Writes to requested open                         | the app; the Trigger (true) and Close (false) through `DialogContext.setOpen`; `DialogSession` for an accepted dismissal and for a native close it didn't start                                                                                                  | the same readers                                                                                                                              |
| Dismissible                                      | the effective root Options, as above                                                                                                                                                                                                                             | root State; `DialogSession`'s layer, captured in a branch snapshot with the policy object as its revision                                     |
| Role                                             | `DialogContext.role`, from the package-private `ɵOrigamiDialogRole` on the root's own element (provided by `OrigamiAlertDialog`), else `dialog`                                                                                                                  | Content's `role` binding; `DialogSession`'s outside containment (an alert dialog has no outside)                                              |
| Trigger slot                                     | `DialogContext`, set by the Trigger's `ngOnInit`, cleared by its `DestroyRef`; a second Trigger throws                                                                                                                                                           | Content's focus fallback (`DialogSession`)                                                                                                    |
| Content slot                                     | `DialogContext`, set by Content's `ngOnInit` with its session's part; a second Content throws                                                                                                                                                                    | the Trigger's `aria-controls`; `DialogSession`, which opens only as the registered part                                                       |
| Title IDs                                        | `DialogContext`'s list, appended by each Title's `ngOnInit`, removed by its `DestroyRef`                                                                                                                                                                         | Content's `aria-labelledby`                                                                                                                   |
| Description IDs                                  | `DialogDescriptions` on Content, appended by the `ngOnInit` of each Description inside it whose nearest root is Content's, removed by its `DestroyRef`                                                                                                           | Content's single `ɵOrigamiDescribedBy` registration                                                                                           |
| Content `aria-labelledby` static value, snapshot | Content, read at construction; a `linkedSignal` marks it the server's output once the Title IDs equal it                                                                                                                                                         | Content's `aria-labelledby` binding                                                                                                           |
| Content `aria-describedby`                       | Content's `ɵOrigamiDescribedBy`, shared with other describers on the element                                                                                                                                                                                     | the element                                                                                                                                   |
| Native session: active, order, activation        | `DialogSession`, written only in its after-render WRITE, its `close` listener and its destruction                                                                                                                                                                | the layer (`isParticipating`, `order`, `activation`), `ModalSessions`                                                                         |
| Readiness, epoch                                 | `DialogSession`: ready from `showModal()` until a close is observed; the epoch counts flips                                                                                                                                                                      | nested presentations, the layer's close check                                                                                                 |
| Presentation children                            | `DialogSession`, an immutable `Set`; a Popover or Tooltip whose modal scope it is adds itself when its synchronization resolves this session as its parent, however its parts got inside the `<dialog>`                                                          | `DialogSession`'s close (`desired`, `suppress`) and open (`parentRevealed`)                                                                   |
| Retained presence                                | Content's Presence, `present` from requested open                                                                                                                                                                                                                | Content State; `DialogSession`, which calls `close()` once the phase is `closed`                                                              |
| Entering permit and reveal                       | `ɵOrigamiPresencePresentation` on Content, written by `DialogSession`: entry permitted while requested open, the reveal committed while modal, reset when the session ends                                                                                       | Content's Presence, which runs an exit only after a reveal and settles a close after the session's end without one                            |
| Mounted Contents, scroll lock, topmost session   | `ModalSessions`, an application `@Service`: each `DialogSession` registered from construction to destruction; the lock held from `showModal()` to the session's end, with the previous inline `overflow-x` and `overflow-y`                                      | `<html>` inline `overflow`; `DialogSession`'s outside containment and nested Dialogs                                                          |
| Focus return target                              | the effective `OrigamiDialogContentOptions.returnFocus`                                                                                                                                                                                                          | `DialogSession`, when a session ends                                                                                                          |
| Nested Dialogs                                   | computed, not registered: the mounted Contents whose layer's modal scope (`ɵOrigamiLayer.scope()`) is this session's layer, so the innermost Dialog whose `<dialog>` contains theirs in the flat tree, declared, projected or slotted (`ModalSessions.nestedIn`) | this session's end (`endExit`) and native close (`requested`, reported through `ErrorHandler` when true)                                      |
| Modal scope for nested parts                     | `DialogSession`'s layer, registered with `ɵOrigamiLayers` as a modal scope at construction; membership is computed from the DOM by the reader (utils DESIGN)                                                                                                     | a Popover without a parent Popover (presentation and branch parent), a Tooltip outside Popover Content (presentation parent), a nested Dialog |

## Read timing

| Read                                                 | Reader                                                                                                       | Phase                                     | Platform                        | If the owner isn't initialized                                                                                                                                                                                                   |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root Options (`open`, `dismissible`)                 | root State, Trigger, Content, session                                                                        | render, after render, event               | both                            | Safe: an ancestor's, read through `injectDeferred` after construction.                                                                                                                                                           |
| Own Options (`id`, `disabled`, `returnFocus`, …)     | each part                                                                                                    | render; `returnFocus` when a session ends | both                            | Safe: its own.                                                                                                                                                                                                                   |
| `role`                                               | Content's `role` binding; `DialogSession`'s outside containment                                              | construction; event (containment)         | both; browser (containment)     | Safe: the root's element injector is complete when Content is created.                                                                                                                                                           |
| Content slot (`contentId`)                           | Trigger `aria-controls`                                                                                      | render                                    | both                            | Absent until Content registers in `ngOnInit`, so a Trigger never names unset inputs; Angular re-evaluates the binding after registration, in the same change detection on the server.                                            |
| Title IDs                                            | Content `aria-labelledby`                                                                                    | render                                    | both                            | Before a Title registers, the static value. A Title in a child component registers after Content's first evaluation; the signal re-evaluates the binding in the same change detection.                                           |
| Description IDs                                      | Content's `ɵOrigamiDescribedBy`                                                                              | render                                    | both                            | As Title IDs; the shared description's own rules apply (utils/DESIGN.md). A Description outside Content, or inside another root's, registers nothing.                                                                            |
| Trigger slot and its Options                         | `DialogSession` focus fallback                                                                               | after render, event, destroy              | browser                         | No Trigger: no fallback.                                                                                                                                                                                                         |
| Presence phase                                       | `DialogSession`                                                                                              | after render WRITE, effect                | browser                         | Safe: the composed Presence on the same element is constructed first.                                                                                                                                                            |
| Presence's current transition                        | `DialogSession`, to permit and commit it                                                                     | effect, after render WRITE                | both (permit), browser (commit) | Safe: the composed Presence attaches it at construction.                                                                                                                                                                         |
| Native `open`, connection, `getBoundingClientRect`   | `DialogSession`                                                                                              | after render WRITE, event, task           | browser                         | Not connected: no `showModal()` until a later render.                                                                                                                                                                            |
| `ModalSessions` topmost                              | `DialogSession` outside containment                                                                          | event, task                               | browser                         | Safe: written at `showModal()` and session end.                                                                                                                                                                                  |
| Nested Dialogs and their `requested`                 | the enclosing `DialogSession`, at its native close, after nested exits end, computing them from the DOM then | after render WRITE, event, destroy        | browser                         | Safe: a nested Content registers at construction and unregisters at destruction; the enclosing layer stays registered through its own destruction's session end. A Dialog root without mounted Content isn't nested in anything. |
| Nested Dialog session (`endExit`)                    | the enclosing `DialogSession`, when its own session ends, before its `close()`, computing them as above      | after render WRITE, event, destroy        | browser                         | Safe: a nested session that never opened, or is requested open, is left as it is.                                                                                                                                                |
| Parent session `ready`, `requested`, `canPresent`, … | a Popover or Tooltip inside                                                                                  | effect, after render, event               | browser                         | Safe: the session is constructed with Content, before its descendants.                                                                                                                                                           |

`showModal()` and `close()` run only in `DialogSession`'s after-render WRITE (and `close()` in its destruction), never during render or on the server.

## Refresh dependencies

- Opening needs a render after `open` turns true; closing needs one after Presence settles closed. `DialogSession`'s effect tracks requested intent and the Presence phase and marks Content's view for check, so both happen under zoneless change detection.
- Trigger `aria-controls`, Content `aria-labelledby` and `aria-describedby` depend on the render that follows a part's registration; on the server too, so server HTML is complete.
- A nested Dialog whose exit the enclosing session ends marks its Content's view for check, so its Presence settles without the rest of the exit.
- A native close Origami didn't start writes `open` from the `close` event, or from the next after-render WRITE if that runs first. It marks Content's view for check, so Presence's READ settles the close even when `open` was already false.
