# Dialog design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 22. The dismissal layer and the presentation contract Content implements are mapped in [utils/DESIGN.md](../utils/DESIGN.md).

```text
OrigamiAlertDialog      own Options (OrigamiAlertDialogOptions) ──▶ the composed root's OrigamiDialogOptions;
 │                        provides ɵOrigamiDialogRole = "alertdialog" on the root's element
OrigamiDialog (root)    DialogContext: requested open, dismissible, role, registrations
 ├─ Trigger      ──register(ngOnInit)──▶ trigger slot   (aria-controls, focus fallback)
 ├─ Content      ──register(ngOnInit)──▶ content slot
 │    DialogSession (provided on Content): native modal session, layer, modal scope
 │      ──register(construction)──▶ ModalSessions; its layer ──▶ ɵOrigamiLayers' modal scopes
 │    DialogDescriptions (provided on Content): description IDs (Content's ɵOrigamiDescribedBy)
 │    ModalSessions (application): mounted Contents, scroll lock, topmost session, focus-return chain
 │    └─ Description* ──register(ngOnInit)──▶ the nearest Content's description IDs
 ├─ Title*       ──register(ngOnInit)──▶ title IDs        (Content's aria-labelledby)
 └─ Close        ── click ──▶ open = false

injectOrigamiDialogOpener(C)   owner: the caller (Injector, EnvironmentInjector, ApplicationRef, DestroyRef, Location)
 └─ open() ──untracked──▶ DialogMount (the bridge, also the OrigamiDialogRef) + child Injector providing it
      createComponent(C) ──▶ host appended to body, view attached to ApplicationRef
      C's top-level OrigamiDialog ──claim(ngOnInit)──▶ DialogMount; open = true
      claimed root destroyed ──▶ claim released, session ended
      DialogMount ──after every render, READ──▶ root requested closed with no native session, or destroyed? ──▶ teardown, `closed` resolves
      owner or application destroyed ──▶ DialogMount.dispose(): root.endSession() ──▶ Content's DialogSession ends now
        (native close while connected, focus returns) ──▶ teardown, `closed` resolves
      an opener inside C ──OwningMount──▶ DialogMount.own(inner mount)
      Content's DialogSession ends (#end) ──▶ DialogContext.disposeOwnedMounts() ──▶ each inner mount disposed, newest first,
        before the outer's native close
```

| Read                                                                                   | Reader                                                                                                               | Phase                                                            | Platform                        | If the owner isn't initialized                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root Options (`open`, `dismissible`)                                                   | root State, Trigger, Content, session                                                                                | render, after render, event                                      | both                            | Safe: an ancestor's, read through `injectDeferred` after construction.                                                                                                                                                           |
| Own Options (`id`, `disabled`, `returnFocus`, …)                                       | each part                                                                                                            | render; `returnFocus` when a session ends                        | both                            | Safe: its own.                                                                                                                                                                                                                   |

`showModal()` and `close()` run only in `DialogSession`'s after-render WRITE (and `close()` in its destruction, its mount's forced disposal and the session end of the opened dialog whose component opened it, before the host is removed), never during render or on the server.

## Refresh dependencies

- Opening needs a render after `open` turns true; closing needs one after Presence settles closed. `DialogSession`'s effect tracks requested intent and the Presence phase and marks Content's view for check, so both happen under zoneless change detection.
- Trigger `aria-controls`, Content `aria-labelledby` and `aria-describedby` depend on the render that follows a part's registration; on the server too, so server HTML is complete.
- A nested Dialog whose exit the enclosing session ends marks its Content's view for check, so its Presence settles without the rest of the exit.
- A mounted component renders first through `attachView` and `markForCheck`; its root claims the mount and writes `open` in that change detection, and `showModal()` follows in its after-render WRITE. Teardown runs in the READ phase of the render that ends the session: after `close()` in the WRITE phase of the same render, or the render a native close marks for check; when the claimed root is destroyed, the render that destroyed it, never during that destruction.
- A native close Origami didn't start writes `open` from the `close` event, or from the next after-render WRITE if that runs first. It marks Content's view for check, so Presence's READ settles the close even when `open` was already false.
