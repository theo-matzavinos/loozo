# Calendar design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 24.

## Read timing

| Read                                                          | Reader                                               | Phase        | Platform | If the owner isn't initialized                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------- | ---------------------------------------------------- | ------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root Options                                                  | `CalendarContext`, State, every part's host bindings | render       | both     | Safe: an ancestor, read through `injectDeferred` after construction.                                                                                                                                                                                                                                                                |
| Host `data-today`, `data-week-start`                          | `CalendarSeed`                                       | construction | browser  | None to wait for: the root reads its own host, as `injectUniqueId` does. A host without them (a root the browser creates) computes both; the server always computes.                                                                                                                                                                |
| Weeks, heading, weekday labels                                | State, your `@for`                                   | render       | both     | Complete without any cell: they come from Options alone.                                                                                                                                                                                                                                                                            |
| Cell's own day                                                | the cell's attributes, its registration              | render       | both     | Own Options; read only after the cell's `ngOnInit`, so a required `date` is set. A non-canonical day is reported through `ErrorHandler` at registration and the cell stays inert.                                                                                                                                                   |
| Cell registrations                                            | the tab stop                                         | render       | both     | A focused day without a mounted cell doesn't hold the tab stop; the other candidates come from Options, so a cell knows whether it's the tab stop without the others.                                                                                                                                                               |
| Heading registration                                          | the Grid's `aria-labelledby`                         | render       | both     | Absent until the Heading registers, also while it is still dehydrated in another `@defer` boundary: the Grid names only the Field's Labels or its static value. A Heading before the Grid registers before the Grid's host bindings run, also on the server.                                                                        |
| The Grid's static `aria-labelledby`                           | the Grid's Field membership                          | construction | both     | The element's attribute when the Grid is created. Angular writes the element's static attributes (the template's, every directive's `host`, including the Grid's own empty default) before creating its directives, also onto a hydrating server element, so this is the static value and never the server's naming of the Heading. |
| Root form state (`FORM_FIELD.state()`)                        | the Grid's membership: Field ARIA, the Field's State | render       | both     | Read only once the Grid has registered, in `ngOnInit`, after Angular set `[formField]` on the root's element, which precedes it; before that, the static values.                                                                                                                                                                    |
| Pending focus request, cell registrations, the active element | the after-render effect                              | after render | browser  | The request waits until a mounted cell has its day; it is never moved to another cell. It is dropped, without focusing, if Previous or Next has stepped, or once focus has moved to another element, Previous and Next included, even if it came back; focus falling to the body doesn't drop it.                                   |
| `focusin` target, pending request                             | `CalendarContext`'s document listener                | event        | browser  | Any element other than the request's origin taking focus drops the request. Focus falling to nothing, as when the focused cell goes with its month, fires no `focusin`.                                                                                                                                                             |
| Cell text direction (`getComputedStyle`)                      | key handling                                         | event        | browser  | Read when the key is pressed.                                                                                                                                                                                                                                                                                                       |
| `relatedTarget`, pending request                              | the root's `focusout`                                | event        | browser  | Focus leaving to nothing while a request is pending is the focused cell going with its month: no touch.                                                                                                                                                                                                                             |

## Refresh dependencies

- The Grid's `aria-labelledby` reads the Heading's registration. A Heading after the Grid, or in a child component, registers after the Grid's host bindings ran; the registration changes a signal they read, so Angular refreshes the Grid again in the same change detection, also on the server.
- A move or a choice into another month writes `month` (or the value the display follows) and a focus request. The new month's cells register in the render that shows them, and the old ones are destroyed in it; only then does the after-render effect find the target and focus it.
