# Toolbar design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 15.

## Ownership

| Fact                                                  | Owner                                                                                                                                                                                                                      | Readers                                                                                                    |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Orientation                                           | root `OrigamiToolbarOptions`, through `ToolbarContext`                                                                                                                                                                     | the root's host bindings; the roving policy; Toolbar Toggle Groups' root Options                           |
| A control's disabled state and disabled focusability  | the `OrigamiButtonOptions` on the control's element: an item's own (`OrigamiToolbarItem` or a replacement), a Toolbar Toggle's from Toggle, a Toolbar Popover Trigger's from the Popover Trigger, with its root's disabled | the composed `ogButton`'s host bindings; `ɵOrigamiToolbarControl`'s registration and `clicked()`           |
| A Toolbar Toggle's pressed state and State            | its `OrigamiToggleOptions` (by default the Toolbar Toggle's own model and inputs), through the composed Toggle                                                                                                             | the Toggle; applications through the Toolbar Toggle's `state`                                              |
| A Toolbar Popover Trigger's ID and disabled state     | its `OrigamiPopoverTriggerOptions` (by default its own inputs), through the composed Popover Trigger                                                                                                                       | as in [popover/DESIGN.md](../popover/DESIGN.md)                                                            |
| Roving membership and tab stop                        | the Toolbar's `ɵOrigamiRovingFocusContext`; each `ɵOrigamiToolbarControl` and the items of Toolbar groups, which provide no roving focus, register with it in `ngOnInit`                                                   | each control's `[tabindex]`                                                                                |
| Roving policy                                         | the Toolbar's `ɵOrigamiRovingFocusOptions`: its orientation, `preferred` = `[]`                                                                                                                                            | the roving Context                                                                                         |
| A Toolbar group's selection, disabled state and State | the group's own Options, through the composed `ɵOrigamiToggleGroupRoot` or `ɵOrigamiRadioGroupRoot`                                                                                                                        | the group's items (see [toggle-group](../toggle-group/DESIGN.md), [radio-group](../radio-group/DESIGN.md)) |
| That a control or Toolbar group has a Toolbar         | `ToolbarContext`, injected at construction                                                                                                                                                                                 | DI: a control or Toolbar group outside a Toolbar fails there                                               |

## Read timing

| Read                                 | Reader                                                                            | Phase  | Platform | If the owner isn't initialized                                                                                                                             |
| ------------------------------------ | --------------------------------------------------------------------------------- | ------ | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Toolbar orientation                  | root host bindings; Toolbar Toggle Groups' `data-orientation` and State           | render | both     | Safe: the root's own Options, or an ancestor's.                                                                                                            |
| Own element's Button Options         | `ogButton`'s host bindings; the control's registered `disabled` and `focusable`   | render | both     | Safe: the same element, read through `injectDeferred` after construction. A Toolbar Popover Trigger's includes its Popover root's disabled, an ancestor's. |
| Roving tab stop                      | each control's `[attr.tabindex]`                                                  | render | both     | Registered controls only; see the roving focus in [collection/DESIGN.md](../collection/DESIGN.md).                                                         |
| Live disabled state and focusability | `ɵOrigamiToolbarControl.clicked()`, after the composed primitive's click listener | event  | browser  | Safe.                                                                                                                                                      |
