# RadioGroup design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 16.

## Ownership

| Fact                                                                       | Owner                                                                                                                                                                      | Readers                                                                                                                                                                                    |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Checked value, disabled                                                    | `OrigamiRadioGroupOptions`, on `ogRadioGroup` or `ogToolbarRadioGroup`                                                                                                     | `RadioGroupContext` in `ɵOrigamiRadioGroupRoot`                                                                                                                                            |
| An item's value, disabled, focusable when disabled                         | its `OrigamiRadioGroupItemOptions`                                                                                                                                         | the item; the roving focus through its registered item; the composed `ogButton`, which owns the disabled attributes, through the Button Options the item supplies with the root's disabled |
| An item's checked state                                                    | derived: root value equals own value                                                                                                                                       | the item's `aria-checked`, `data-checked`                                                                                                                                                  |
| Roving membership and tab stop                                             | the nearest `ɵOrigamiRovingFocusContext`: `ogRadioGroup`'s own, or the Toolbar's for `ogToolbarRadioGroup`; each item registers in `ngOnInit`                              | the item's `[tabindex]`                                                                                                                                                                    |
| Roving policy (standalone)                                                 | `ogRadioGroup`'s `ɵOrigamiRovingFocusOptions`: orientation `"both"`, `preferred` = `[value]` or `[]`                                                                       | the roving Context                                                                                                                                                                         |
| What a keyboard navigation means                                           | `RadioGroupContext`, subscribed to the `navigations` of a roving Context on its own element: only `ogRadioGroup` provides one, so only a standalone group checks on a move | —                                                                                                                                                                                          |
| Value, touched, readonly, required, validation, errors                     | Angular's `FieldState`, bound by the `[formField]` on the root's element                                                                                                   | `RadioGroupContext` (`FORM_FIELD`, self): the readonly guard in `select`; `ogRadioGroup`'s `ɵOrigamiFieldMembership`: its ARIA and the Field                                               |
| Field membership: form state reader (not labelable)                        | the nearest `ogField`'s control slot, set by `ogRadioGroup`'s registration in `ngOnInit`; `ogToolbarRadioGroup` never registers                                            | the Field's State and data attributes                                                                                                                                                      |
| Label IDs                                                                  | the nearest Field's Label slot, set by each `ogFieldLabel` in `ngOnInit`                                                                                                   | `ogRadioGroup`'s `aria-labelledby`, through its membership, while it is the Field's control                                                                                                |
| Description and Error IDs                                                  | the nearest Field                                                                                                                                                          | `ogRadioGroup`'s membership, which registers them with `ɵOrigamiDescribedBy` while it is the Field's control                                                                               |
| `aria-describedby`                                                         | `ɵOrigamiDescribedBy` (`/utils`), composed by `ogRadioGroup`                                                                                                               | the element                                                                                                                                                                                |
| Static `aria-labelledby`, `aria-invalid`, `aria-required`, `aria-readonly` | the element, read at construction by the membership                                                                                                                        | `ogRadioGroup`'s bindings outside a Field and as a second control the Field ignores                                                                                                        |
| Touch notification                                                         | `RadioGroupContext`'s Observable, emitted when `ogRadioGroup`'s `focusout` moves focus outside its element                                                                 | `ogRadioGroup`'s `touch` output, which `[formField]` listens to                                                                                                                            |
| The element `focus()` focuses                                              | `ogRadioGroup`'s own roving Context's tab stop                                                                                                                             | `focus()`, which `focusBoundControl()` calls                                                                                                                                               |

## Read timing

| Read                                    | Reader                                                                              | Phase        | Platform | If the owner isn't initialized                                                                                                                                                                  |
| --------------------------------------- | ----------------------------------------------------------------------------------- | ------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Own value, root value                   | the item's `checked`                                                                | render       | both     | Safe: own inputs and an ancestor.                                                                                                                                                               |
| Root disabled                           | root host bindings; the item's Button Options                                       | render       | both     | Safe.                                                                                                                                                                                           |
| Roving tab stop                         | item `[attr.tabindex]`                                                              | render       | both     | See the roving focus in [collection/DESIGN.md](../collection/DESIGN.md).                                                                                                                        |
| Own Options, root disabled              | `activate()`                                                                        | event        | browser  | Safe; rechecked after `focus()`.                                                                                                                                                                |
| `FORM_FIELD.state().readonly()`         | `RadioGroupContext.select`                                                          | event        | browser  | Safe: read at selection time; without `[formField]`, absent.                                                                                                                                    |
| `FORM_FIELD.state()`                    | the Field, through the membership; `aria-invalid`, `aria-required`, `aria-readonly` | render       | both     | Angular sets `[formField]` on the same element before the root's first host-binding update; without it, absent.                                                                                 |
| The Field's slot, Label IDs             | `[attr.aria-labelledby]`, through the membership                                    | render       | both     | Before its own registration the root isn't the member: it renders its static value. A Label in a later sibling view or a child component is absent until it registers; server HTML is complete. |
| The Field's slot, Description/Error IDs | the root's `ɵOrigamiDescribedBy` registration                                       | render       | both     | As for any Field control (see the [Field design map](../field/DESIGN.md)).                                                                                                                      |
| Static attributes                       | the membership                                                                      | construction | both     | Safe: the element's own. Under hydration it may be the server's output, which the member never reads; outside a Field and as an ignored control the server rendered the same static value.      |
| `focusout` `relatedTarget`              | the touch notification                                                              | event        | browser  | Safe: the event's own; null (focus left to nothing) touches.                                                                                                                                    |
| Own roving tab stop                     | `focus()`                                                                           | event        | browser  | Safe: read when called; null focuses nothing.                                                                                                                                                   |
