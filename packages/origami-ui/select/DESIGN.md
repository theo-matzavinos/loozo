# Select design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 23. The composed Popover's own map is in [popover/DESIGN.md](../popover/DESIGN.md).

## Ownership

| Fact                                                                                           | Owner                                                                                                                                                                                                                                                                             | Readers                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Value, requested open, disabled                                                                | `OrigamiSelectOptions<T>` on `ogSelect`, or `OrigamiSelectMultipleOptions<T>` on `ogSelectMultiple`; the root's private `SelectRootOptions` adapts them (whether it's multiple, what "selected" means, what choosing writes and whether it closes) for the shared `SelectContext` | `SelectContext`; `OrigamiSelectState`; the composed Popover root, through the `OrigamiPopoverOptions` the root supplies (`open`, `disabled`, `dismissible: true`)        |
| Option registrations (element, id, value, disabled, label)                                     | each `ogSelectOption`, registered with `SelectContext` in `ngOnInit` and removed by its `DestroyRef`                                                                                                                                                                              | option `aria-selected`; `selectedOption()`; navigation and typeahead                                                                                                     |

| `selectedOption()`, `selectedOptions()`                                                        | derived by `OrigamiSelectState` or `OrigamiSelectMultipleState` from the root value and the registrations: the first registered match, per value in value order for the multiple root                                                                                             | consumer templates (the Trigger text)                                                                                                                                    |

## Read timing

| Read                                   | Reader                                                    | Phase        | Platform | If the owner isn't initialized                                                                                                                                          |
| -------------------------------------- | --------------------------------------------------------- | ------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root Options                           | every part's host bindings, State                         | render       | both     | Safe: an ancestor, read through `injectDeferred` after construction.                                                                                                    |
| Own value vs root value                | option `aria-selected`, `data-selected`, State `selected` | render       | both     | Safe: own Options and an ancestor. A null or unknown root value selects nothing.                                                                                        |
| Option registrations                   | `selectedOption()`                                        | render       | both     | An option not registered yet is absent: the record is null, then the reading view refreshes when it registers (see below).                                              |
| Content registration (participation)   | Trigger `aria-activedescendant`, `state.open()`           | render       | both     | Absent until Content registers: not participating, no active descendant. False on the server.                                                                           |
| Active option                          | Trigger `aria-activedescendant`, option `data-active`     | render       | both     | No active option before a user event; a removed option isn't active; none exposed while not participating. Never on the server.                                         |
| Option registrations, DOM order        | navigation, typeahead, opening's highlight                | event        | browser  | An unmounted or dehydrated option isn't a candidate. DOM order is read at the event.                                                                                    |
| Option text (without a `label`)        | typeahead                                                 | event        | browser  | The element's `textContent`, read when the key is pressed.                                                                                                              |
| Participation                          | the Trigger's Escape guard, an option's pointer move      | event        | browser  | Not participating: the Trigger closes on Escape itself; a pointer move highlights nothing.                                                                              |
| Participation, requested open          | the active-option reset                                   | effect       | both     | Not participating since the last user open: nothing to lose, so the opening frame keeps the active option a key set. Never set on the server.                           |
| Registered Trigger `labelledBy()`      | Content `aria-labelledby`                                 | render       | both     | Absent until the Trigger registers; a Trigger in a later view or a child component refreshes Content in the same change detection, also on the server.                  |
| Content's template `aria-labelledby`   | Content `aria-labelledby`, while the Trigger has none     | construction | both     | `HostAttributeToken`: the template's static value, never the hydrated element's bound one; a `hostDirectives` composer's `host` value isn't seen.                       |
| Content's template `aria-label`        | Content `aria-label`                                      | construction | both     | `HostAttributeToken`, as above: a name copied from the Trigger into server HTML is never taken for Content's own.                                                       |
| The Trigger's template `aria-label`    | its registration, so Content `aria-label`                 | construction | both     | `HostAttributeToken`; a bound `aria-label` isn't seen. Content reads it only once the Trigger has registered, and loses it when the Trigger is destroyed.               |
| Root form state (`FORM_FIELD.state()`) | the Trigger's membership: Field ARIA, the Field's State   | render       | both     | Read only once the Trigger has registered, in `ngOnInit`, after Angular set `[formField]` on the root's element, which precedes it; before that, the static values.     |
| Root form state `readonly()`           | `choose`                                                  | event        | browser  | Without `[formField]`, not readonly.                                                                                                                                    |
| Registered Trigger element             | the root's `focus()`                                      | event        | browser  | Nothing before the Trigger registers.                                                                                                                                   |
| Floating readiness, the pending reveal | Content's scroll                                          | after render | browser  | Waits until the list is revealed (`ready()`), so the list has its size and position; then reads the option's and the scrolling box's rectangles and writes `scrollTop`. |

## Refresh dependencies

- `selectedOption()` or `selectedOptions()` read in the Trigger's text before the options' `ngOnInit`: the registration changes a signal the Trigger's binding read, so Angular refreshes that view again in the same change detection; on the server too, so server HTML has the label.
- Disabling closes an open Select from an effect that watches the root's disabled state for a change from enabled to disabled, and the active option and typeahead buffer are cleared by an effect when the requested state closes or participation changes from true to false (an enclosing layer's close keeps the request). That effect starts with participation false, so the opening frame, where a key sets the active option before the list first participates, doesn't clear it. Every user open resets the buffer and sets the active option itself, so neither depends on those effects having run.
