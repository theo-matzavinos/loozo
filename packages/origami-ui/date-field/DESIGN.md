# Date field design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 25.

## Ownership

| Fact                                                                                                    | Owner                                                                                        | Readers                                                                                           |
| ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Value, locale, disabled, readonly                                                                       | the root's Options (`OrigamiDateFieldOptions`, effective: the root itself, or a replacement) | `DateFieldRoot` (each root's adapter), then `DateFieldContext`, State, the Input and the segments |
| Value shape (units, parse, format, canonical value)                                                     | each root's strategy (`dateValue` for `ogDateField`) in `DateFieldRoot`                      | `DateFieldDraft`, the layout, paste                                                               |
| Parser: `transformedValue` over the effective value, cast to `ModelSignal` (F3)                         | `DateFieldDraft`, provided by the root, created on its first read (A1)                       | Signal Forms (parse errors, `reset()`), the draft's writers, State `parseErrors`                  |
| Draft (each unit's digits)                                                                              | `DateFieldDraft`'s raw value; replaced on a value change and on `reset()`                    | segment text and ARIA, State `segments`, the engine's steps and bounds                            |
| Typing buffer (the digits typed into the focused segment since it took focus, and the draft they left)  | `DateFieldContext`                                                                           | typing, Backspace                                                                                 |
| Unit rules (typing, advance, bounds, steps, Home/End, erasing, day periods, digit values)               | the segment engine (`date-field-unit.ts`), framework-free                                    | `DateFieldContext`                                                                                |
| Layout: order, literals, unit names, hour cycle, day periods, digits                                    | derived by `DateFieldContext` from `Intl` (`resolveLayout`), or the seed                     | State `segments`, segment text, names and month names, the root's `data-layout`                   |
| Layout seed                                                                                             | the root host's `data-layout`, written by the server's render                                | `DateFieldContext` when it is created in the browser                                              |
| Segment registrations (element, effective unit)                                                         | each `ogDateFieldSegment`, registered with `DateFieldContext` in `ngOnInit`                  | focus moves, auto-advance, `focus()`                                                              |
| Input registration (element, the Field membership's `aria-labelledby`, `aria-invalid`, `aria-required`) | `ogDateFieldInput`, registered with `DateFieldContext` in `ngOnInit`; one per root           | the segments' `aria-labelledby`, `aria-invalid` and `aria-required`                               |
| Field membership and its ARIA (`aria-labelledby` IDs, `aria-invalid`, `aria-required`)                  | the Input's `ɵOrigamiFieldMembership`, reading the root's `FORM_FIELD`                       | the Input's host bindings, the segments through the Input registration, the Field                 |
| The Input's `aria-describedby`                                                                          | `ɵOrigamiDescribedBy`, composed by the Input                                                 | —                                                                                                 |
| Pending `focus()` request                                                                               | `DateFieldContext`                                                                           | its after-render effect                                                                           |
| Composition in progress                                                                                 | each segment                                                                                 | its `compositionend`                                                                              |
| Touch                                                                                                   | `DateFieldContext`'s `touches`, emitted by the Input's `focusout`                            | the root's `touch` output, Signal Forms                                                           |

## Read timing

| Read                                               | Reader                                                          | Phase                                                            | Platform | Before the owner is ready                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Root Options                                       | `DateFieldRoot`'s factory, through `injectDeferred`             | render, event                                                    | both     | The root is an ancestor of every part, resolved after its construction: the direct case's Options are the root under construction, so nothing resolves them in a constructor (NG0200, SPEC section 3).                                                                                                                                                                                           |
| `DateFieldDraft` (creates the parser)              | `DateFieldContext`, through `injectDeferred` inside `untracked` | first read: render (a segment's text, State `segments`) or event | both     | Before the first read there is no draft, so Signal Forms sees no parse errors and has no reset callback, and there is nothing to discard. Created outside reactive context because `transformedValue` writes Signal Forms' parse-error source (NG0600 in a `computed`); in the root's node injector, so `self: true` finds the `[formField]` on the root's element, also under `hostDirectives`. |
| Host `data-layout`                                 | `DateFieldContext`'s constructor                                | construction                                                     | browser  | None: the root reads its own server element. On the server and for a browser-created root, there is no seed and the layout comes from `Intl`. The attribute is validated later, by the layout's first computation, against the root's shape.                                                                                                                                                     |
| Layout (`linkedSignal` over locale and hour cycle) | State, segments, the root's `data-layout`                       | render                                                           | both     | Complete with no segment mounted. The first computation takes the seed if it is valid for the root's units and hour cycle, else `Intl`'s; a later locale change recomputes.                                                                                                                                                                                                                      |
| Draft                                              | segment text, ARIA values, `data-placeholder`, State `segments` | render                                                           | both     | —                                                                                                                                                                                                                                                                                                                                                                                                |
| Draft, typing buffer, layout, clock year           | typing, steps, Home/End, erasing, paste                         | event                                                            | browser  | The current year is read at the keypress, never at render.                                                                                                                                                                                                                                                                                                                                       |
| Input registration                                 | segments' `aria-labelledby`, `aria-invalid`, `aria-required`    | render                                                           | both     | Absent until the Input registers: no `aria-labelledby`, no `aria-invalid` or `aria-required`.                                                                                                                                                                                                                                                                                                    |
| The Input's static ARIA                            | the Input's Field membership                                    | construction                                                     | both     | —                                                                                                                                                                                                                                                                                                                                                                                                |
| Root form state (`FORM_FIELD.state()`)             | the Input's membership: Field ARIA and the Field's State        | render                                                           | both     | null without `[formField]`.                                                                                                                                                                                                                                                                                                                                                                      |
| Segment registrations                              | focus moves, auto-advance, `focus()`                            | event                                                            | browser  | A missing neighbour is skipped; `focus()` with none mounted becomes a request.                                                                                                                                                                                                                                                                                                                   |
| Pending request, segment registrations             | the after-render effect                                         | after render                                                     | browser  | Waits until a segment is mounted.                                                                                                                                                                                                                                                                                                                                                                |
| Segment text direction (`getComputedStyle`)        | ArrowLeft and ArrowRight                                        | event                                                            | browser  | —                                                                                                                                                                                                                                                                                                                                                                                                |

| Event phase (`EventPhase.REPLAY`)                  | segment `beforeinput`, `keydown`, `paste`                       | event                                                            | browser  | A replayed event's default already happened: it isn't prevented, and a replayed Backspace or Delete is left to its replayed `beforeinput`.                                                                                                                                                                                                                                                       |

## Refresh dependencies

- The segments' `aria-labelledby`, `aria-invalid` and `aria-required` read the Input's registration. The Input is their ancestor and registers in its `ngOnInit`, before the segments' host bindings run in the same pass; a later registration changes a signal they read, so Angular refreshes them again in the same change detection, also on the server.
- A committed value changes the effective value, which recomputes the draft (`transformedValue`'s raw `linkedSignal`) and every segment's text in the next render.
- `focus()` before any segment is mounted: the segments register in the render that mounts them; only then does the after-render effect focus the first one.
