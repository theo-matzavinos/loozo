# Date field design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 25.

## Ownership

| Fact                                                                                                                    | Owner                                                                                                                                                                                                    | Readers                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Value, locale, disabled, readonly; a time root's precision and hour cycle                                               | the root's Options (`OrigamiDateFieldOptions` or `OrigamiTimeFieldOptions`, effective: the root itself, or a replacement)                                                                                | `DateFieldRoot` (each root's adapter), then `DateFieldContext`, State, the Input and the segments                                                   |
| Value shape (units, parse, format, canonical value)                                                                     | each root's strategy in `DateFieldRoot`: `dateValue` for `ogDateField`; `timeValue` for `ogTimeField`, whose units follow the precision and which formats and parses in the layout's resolved hour cycle | `DateFieldDraft` (with the resolved hour cycle from `DateFieldContext`), the layout (units), paste                                                  |
| Parser: `transformedValue` over the effective value, cast to `ModelSignal` (F3)                                         | `DateFieldDraft`, provided by the root, created on its first read (A1)                                                                                                                                   | Signal Forms (parse errors, `reset()`), the draft's writers, State `parseErrors`                                                                    |
| Draft (each unit's digits, the day period's `am`/`pm`, in the resolved hour cycle; the second only at second precision) | `DateFieldDraft`'s raw value; replaced on a value change, on `reset()`, by the root's `clear()` and by `refresh()` on a change of the resolved hour cycle or a time root's precision                     | segment text and ARIA, State `segments`, the engine's steps and bounds                                                                              |
| Typing buffer (the digits typed into the focused segment since it took focus, and the draft they left)                  | `DateFieldContext`                                                                                                                                                                                       | typing, Backspace; discarded by every other edit, by `clear()` and by a layout refresh                                                              |
| Unit rules (typing, advance, bounds, steps, Home/End, erasing, day periods, digit values)                               | the segment engine (`date-field-unit.ts`), framework-free                                                                                                                                                | `DateFieldContext`                                                                                                                                  |
| Layout: order, literals, unit and day period names, resolved hour cycle, day period names, digits                       | derived by `DateFieldContext` from `Intl` (`resolveLayout`), or the seed                                                                                                                                 | State `segments`, segment text, names and month names, the root's `data-layout`; its hour cycle: the engine and `DateFieldDraft`'s format and parse |
| Layout seed                                                                                                             | the root host's `data-layout`, written by the server's render                                                                                                                                            | `DateFieldContext` when it is created in the browser                                                                                                |
| Segment registrations (element, effective unit)                                                                         | each `ogDateFieldSegment`, registered with `DateFieldContext` in `ngOnInit`                                                                                                                              | focus moves, auto-advance, `focus()`                                                                                                                |
| Input registration (element, the Field membership's `aria-labelledby`, `aria-invalid`, `aria-required`)                 | `ogDateFieldInput`, registered with `DateFieldContext` in `ngOnInit`; one per root                                                                                                                       | the segments' `aria-labelledby`, `aria-invalid` and `aria-required`                                                                                 |
| Field membership and its ARIA (`aria-labelledby` IDs, `aria-invalid`, `aria-required`)                                  | the Input's `ɵOrigamiFieldMembership`, reading the root's `FORM_FIELD`                                                                                                                                   | the Input's host bindings, the segments through the Input registration, the Field                                                                   |
| The Input's `aria-describedby`                                                                                          | `ɵOrigamiDescribedBy`, composed by the Input                                                                                                                                                             | —                                                                                                                                                   |
| Pending `focus()` request                                                                                               | `DateFieldContext`                                                                                                                                                                                       | its after-render effect                                                                                                                             |
| Composition in progress                                                                                                 | each segment                                                                                                                                                                                             | its `compositionend`                                                                                                                                |
| Touch                                                                                                                   | `DateFieldContext`'s `touches`, emitted by the Input's `focusout`                                                                                                                                        | the root's `touch` output, Signal Forms                                                                                                             |

## Refresh dependencies

- The segments' `aria-labelledby`, `aria-invalid` and `aria-required` read the Input's registration. The Input is their ancestor and registers in its `ngOnInit`, before the segments' host bindings run in the same pass; a later registration changes a signal they read, so Angular refreshes them again in the same change detection, also on the server.
- A committed value changes the effective value, which recomputes the draft (`transformedValue`'s raw `linkedSignal`) and every segment's text in the next render.
- `focus()` before any segment is mounted: the segments register in the render that mounts them; only then does the after-render effect focus the first one.
- A change of a time root's resolved hour cycle (its `hourCycle`, or a locale with another default) recomputes the layout, which changes `DateFieldContext.hourCycle`, which the draft's format reads: the draft is formatted again from the value. A change of precision recomputes the layout and, since the time shape's format reads it too, the draft.
