# Pagination design map

Ownership and read timing. Usage is in the [README](README.md); the contract is SPEC section 39.

## Ownership

| Fact                                                       | Owner                                                                                                                             | Readers                                                     |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Root Options (page, total, pageSize, siblings, boundaries) | the root directive through `OrigamiPaginationOptions` (`provideExisting`), or a composer's whole replacement                      | the Context (deferred with `injectDeferred`)                |
| Requested page                                             | the root Options' writable `page`; written only by an item's or step's activation, at most once per activation                    | the Context: `from`/`to` and the write rule's equality      |
| Page count, effective page, item bounds, neighbours, range | the Context's `computed`s, calling the framework-free `pagination-math.ts`                                                        | State; the parts' host bindings and click handlers          |
| A page item's or link's page                               | its own directive through `OrigamiPaginationItemOptions`, or a composer's replacement                                             | that part's mark and, for an item, its target               |
| A step's target                                            | the step: First 1, Last the page count, Previous and Next the Context's neighbours; none with no pages                            | the step's composed Button Options (disabled) and its click |
| Disabled attributes                                        | the composed `ogButton`, from Options the item or step supplies whole: disabled by the write rule, always `focusableWhenDisabled` | the browser                                                 |
| Landmark, names, gap markup, summary text                  | the consumer                                                                                                                      | the browser; Origami never reads or writes them             |
| Link destinations                                          | the consumer's router (`routerLink`, `href`)                                                                                      | the browser; Origami adds no listener to a link             |

| Read                                                 | Reader                                                                                                                                     | Phase                                              | Platform | If the owner isn't initialized                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root Options                                         | the Context's `computed`s, through State or a part's host bindings                                                                         | construction at the earliest, render at the latest | both     | Deferred with `injectDeferred`: resolved on the first evaluation of a Context `computed`, whichever comes first, a State read or a part's host bindings in the first update pass. ## Refresh dependencies

- None for the first render: every bound fact is computed synchronously from Options no later than a part's host-binding pass, on the server too. Server HTML needs no second pass.
- Every Options source (`page`, `total`, `pageSize`, `siblings`, `boundaries`, an item's or link's `page`) is a signal the bound `computed`s track. A write marks the views whose host bindings read it, the root's declaring view and any child view holding a part, and they refresh in the same change detection.
- No registration: parts read the nearest root's Context and their own Options only, never a sibling's, so mount order and teardown need no bookkeeping.
- Hydration: a part in a still-dehydrated `@defer` block keeps the server's attributes until it hydrates, then renders the live State on the same node. A click replayed after hydration reads the live State at replay. Angular reuses a dehydrated `@for` block's server views in DOM order, so a range whose root's page changed before the block hydrated replays a click on the node now rendering the live range's entry in that slot.
